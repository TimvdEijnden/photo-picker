# photo picker

Review and select photos in the browser. Launched from the command line. Press space to copy keepers to an output folder.

Starts a web server at default port 3000 and opens your default browser.

### usage

```bash
npx photo-picker <source-dir> <dest-dir> [port]
```

### controls

| key | action |
|---|---|
| `←` | previous photo |
| `→` | next photo |
| `space` | copy to dest and advance |
